# BBG · Automated Installer

Maintained by **SANDBAAD**.

## Usage

```bash
git clone https://github.com/SANDBAAD/BBG
cd BBG
bash installer/install.sh
```

## Optional Environment Variables

| Variable | Default | Purpose |
| :--- | :--- | :--- |
| `RAILWAY_TOKEN` | — | Account token |
| `RAILWAY_PROJECT_ID` | — | Existing project ID |
| `BBG_PROJECT` | `bbg-panel` | Project name |
| `BBG_REPO` | `https://github.com/SANDBAAD/BBG` | Repository URL |
| `BBG_PANEL_PORT` | `8080` | HTTP panel & edge reverse-proxy port |
| `BBG_TCP_PORT` | `8443` | Single-port TCP SNI multiplexer port |
